# Les articles indéfinis

You don't know it. Are used for items that can be counted or categorized, but are unspecified. 

| un       | une     | des     |
| -------- | ------- | ------- |
| masculin | féminin | pluriel |

## Par exemples

- des livres = some books
- des voitures = some cars

# Les articles partitifs

Are used for uncountable masses, portions, or abstract concepts.

| de la               | de l'                     | du                   | des     |
| ------------------- | ------------------------- | -------------------- | ------- |
| singulier + féminin | singulier + une voyelle   | masculin + singulier | pluriel |
|                     | singulier + un « h » muet |                      |         |

|     |        |                             |
| --- | ------ | --------------------------- |
| du  | some   | quantité indéterminée       |
| du  | of the | contraction de 'de' et 'le' |

## Par exemples

| votre    | notre | leurs  |
| -------- | ----- | ------ |
| your own | ours  | theirs |
