# Les pronoms relatifs « QUI » et « QUE »

## Qui

qui + verbe conjugué

Si on dit « La voiture **qui** me dépasse », "qui" est le sujet de dépasse.

- Use **qui** when the word is **doing** the action (the subject).
- **Subject** = does the action -> use **qui**

### Par exemples

- Donne-moi le livre. **_Le livre_** est sur la table
	- Donne-moi le livre **_qui_** est sur la table
- La personne est souriante. **_La personne_** vient
	- La personne **_qui**_ vient est souriante
- **_Le chien_** aboie. Le chien est gentil
	- Le chien **_qui_** aboie est gentil
- La voiture est garée. **_La voiture_** est rouge
	- La voiture **_qui_** est garée est rouge

## Que

que + sujet + verbe conjugué

Si on dit « La voiture **que** je dépasse », "que" serait le COD de dépasse (c'est vous qui dépassez la voiture).

- Use **que** when the word is **receiving** the action (the object).
- **Object** = receives the action -> use **que**

### Par exemples

- Elle part en vacances avec des personnes. Elle ne connaît pas **_ces personnes_**.
	- Elle part en vacances avec des personnes **_qu_**'elle ne connaît pas.

## La Règle

« Qui » reprend le sujet de la deuxième phrase.

« Qui » peut être une chose, un animal, une personne.

« Qui » est placé après le nom qu’il reprend.

« Que » pour reprend le COD de la deuxième phrase.
